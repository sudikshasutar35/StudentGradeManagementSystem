# Student Grade Management System

## Project Overview
A console-based Java application that stores student names and marks, calculates academic statistics, assigns grades, and displays pass/fail results.

## Features
- Accepts student names and marks from the user
- Validates student count, names, and marks
- Calculates average, highest, and lowest marks
- Assigns grades based on marks
- Determines pass/fail status
- Displays a formatted student report

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Conditional Statements and Loops

## Grading Criteria
| Marks | Grade |
|---|---|
| 90–100 | A |
| 80–89.99 | B |
| 70–79.99 | C |
| 60–69.99 | D |
| Below 60 | F |

**Passing Criteria:** Marks greater than or equal to 40 are considered PASS.

## Requirements
- Java JDK installed
- Terminal or command prompt

## How to Run

Compile the source files:

```bash
javac Student.java Main.java
```

Run the application:

```bash
java Main
```
